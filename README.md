# 3D 홍콩 마작 프로토타입

기존 Three.js HTML을 독립 프로젝트로 옮긴 버전입니다. `index.html`을 웹 서버에서 열면 3D 테이블을 볼 수 있습니다. Three.js는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

로컬 확인: `python -m http.server 8000` 실행 후 `http://localhost:8000/mahjong-game/` 열기.

현재 범위: 144패 벽, 주사위 개벽, 한 지점부터 연속된 53패 소모, 동가의 손패 표시. 턴, 버리기, 치·퐁·깡, 승리 판정, 꽃패 보충은 아직 구현되지 않았습니다.

GitHub Pages에 배포할 때는 이 디렉터리를 독립 저장소의 루트로 옮기고 Pages의 배포 소스를 `main` 브랜치 루트로 설정하면 됩니다.
