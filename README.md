# 3D 홍콩 마작 프로토타입

기존 Three.js HTML을 독립 프로젝트로 옮긴 버전입니다. `index.html`을 웹 서버에서 열면 3D 테이블을 볼 수 있습니다. Three.js는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

이 폴더에서 로컬 확인: `python -m http.server 8000` 실행 후 `http://localhost:8000/` 열기.

현재 범위: 144패 벽, 주사위 개벽, 4장씩 배패, 벽 바깥에 세운 손패, 사용자의 패 뽑기·버리기, 3명 상대의 자동 턴, 치·퐁·깡, 꽃·계절패 보충, 네 묶음과 한 쌍 화료 판정, 벽 소진 유국. 버린 패는 게임판 가운데와 플레이어 목록에 표시하며 게임판 중앙의 최근 버림패를 누르면 전체 목록을 읽을 수 있습니다. 방금 뽑은 패를 잠시 강조하고 손패의 완성 묶음·같은 패 짝·연속 후보를 색으로 표시합니다. 화료·유국 후 결과 화면에서 다음 판으로 넘어가며, 네 플레이어가 동 자리를 한 번씩 맡는 4판 동안 승수를 집계합니다. 화면 아래의 규칙 안내는 처음 하는 사람을 위한 단순화 규칙입니다. 점수, 최소 번수, 특수 화료형, 연장 대국, 플레이어별 독립 화면은 구현되지 않았습니다.

GitHub Pages에 배포할 때는 이 디렉터리를 독립 저장소의 루트로 옮기고 Pages의 배포 소스를 `main` 브랜치 루트로 설정하면 됩니다.
